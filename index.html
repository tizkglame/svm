1Introduction to SVM

  • SVM (Support Vector Machine) is a supervised machine learning algorithm — meaning it learns from labeled data (input + correct output already given).
  • It is used mainly for classification problems (putting data into categories), but a version called SVR (Support Vector Regression) also handles regression (predicting numbers).
  • Invented by Vladimir Vapnik and colleagues (based on Statistical Learning Theory) in the 1990s.
  • Core idea in one line: SVM finds the best possible boundary (line/plane) that separates different classes of data with the maximum possible gap.
Definition
Support Vector Machine is a discriminative classifier formally defined by a separating hyperplane. Given labeled training data, the algorithm outputs an optimal hyperplane which categorises new, unseen examples.

Real life analogy

Imagine two groups of students standing in a playground — "Maths lovers" on one side and "Science lovers" on the other. You want to draw one straight line on the ground that separates the two groups as cleanly as possible, and you also want the line to stay as far away as possible from both groups (so that even if one student takes a small step, the line still correctly separates them). That "safest, most balanced" line is exactly what SVM tries to find.

2Why SVM? Intuition First

Suppose we have two classes of points (●red and ▲blue) that are linearly separable — many lines can separate them. SVM asks: "which one of the infinite possible lines is the BEST?"

Fig 2.1 — Many lines can separate the classes, but only ONE has the maximum margin on both sides.

Why "maximum margin" matters A line squeezed too close to one class is risky — new/unseen points of that class may fall on the wrong side. A line with a bigger cushion (margin) on both sides generalises better to new data. This is the heart of SVM's philosophy.

3Hyperplane & Decision Surface

  • A hyperplane is the decision boundary that separates classes.
  • In 2D (2 features) → hyperplane is a simple line.
  • In 3D (3 features) → hyperplane is a flat plane.
  • In n-dimensions (n features) → hyperplane is an (n−1) dimensional flat "surface" — this general surface is what we call the decision surface.
General equation of a hyperplane:
w · x + b = 0

where:
  w = weight vector (perpendicular / normal to the hyperplane, decides orientation)
  x = input feature vector
  b = bias term (shifts the hyperplane away from origin)
  w · x = dot product = w1x1 + w2x2 + ... + wnxn

For a point to be classified, we simply check which side of the hyperplane it falls on:

If w·x + b > 0 → predict class +1
If w·x + b < 0 → predict class −1
Note
"Decision surface" and "hyperplane" are used interchangeably in SVM literature — decision surface is just the general term (works for any dimension), hyperplane is the mathematical name for that flat surface.

4Margin & Support Vectors

Fig 4.1 — The solid line is the hyperplane; dashed lines mark the margin boundary; circled points are support vectors.

Support Vectors
The data points that lie closest to the hyperplane (right on the edge of the margin). They are the most "critical" / "difficult" points — removing any other point does not change the hyperplane, but removing a support vector CAN change it. This is why the algorithm is named after them!
Margin
The distance between the hyperplane and the nearest data point(s) from either class. SVM tries to maximise this margin → hence also called a Maximum Margin Classifier.
  • Only support vectors decide the position of the hyperplane.
  • Points far from the boundary have no influence on the model.
  • This makes SVM memory-efficient at prediction time — it only needs to "remember" support vectors, not the whole dataset.

5Mathematical Formulation (Linear SVM)

Let training data be (xi, yi) where yi ∈ {+1, −1}.

Step 1 — Canonical hyperplanes

We scale w and b so that the closest points satisfy:

w·x + b = +1   (for positive-class support vectors)
w·x + b = −1   (for negative-class support vectors)

Step 2 — Width of the margin

The perpendicular distance between these two parallel planes works out to:

Margin width = 2 / ‖w‖

where ‖w‖ is the magnitude (norm) of the weight vector. To maximise 2/‖w‖, we must minimise ‖w‖.

Step 3 — The optimisation problem

Minimise:   ½ ‖w‖²
Subject to:   yi (w·xi + b) ≥ 1,   for all i = 1,...,n

This is a convex quadratic optimisation problem — solved using Lagrange multipliers and converted into its dual form:

Maximise:   Σαi − ½ ΣΣ αiαj yiyj (xi·xj)
Subject to:   αi ≥ 0   and   Σαiyi = 0

Here αi are Lagrange multipliers. Points with αi > 0 are exactly the support vectors — every other point gets αi = 0 (confirms what we said in Section 4!).

Why the dual form?
The dual form expresses everything in terms of dot products xi·xj of data points. This one fact is *exactly* what allows the "kernel trick" later (Section 8) — we can replace the dot product with a kernel function without ever needing the primal form.

7Types of SVM

1. Linear SVM
Used when data is linearly separable — a straight line/plane can separate classes directly. Uses the linear kernel (Section 9).
2. Non-Linear SVM
Used when data cannot be separated by a straight line. Data is mapped into a higher dimension using a kernel function, where it becomes linearly separable.

Based on task type, SVM is also grouped as:

  • SVC (Support Vector Classification) — for classification tasks.
  • SVR (Support Vector Regression) — for regression / predicting continuous values, using an "ε-insensitive tube" instead of a strict margin.
  • One-class SVM — used for anomaly / novelty detection (learns the boundary of "normal" data only).

8The Kernel Trick

Real-world data is often not linearly separable in its original space:

Fig 8.1 — Kernel trick lifts data into a higher-dimensional space φ(x) where it becomes linearly separable.

Kernel Trick — Definition
Instead of explicitly transforming every point x → φ(x) into a higher dimension (which is computationally very expensive, sometimes even infinite-dimensional), we use a kernel function K(xi, xj) = φ(xi) · φ(xj) that computes the dot product directly in the original space — giving us the same result as if we had transformed the data, without ever actually doing the transformation.
  • Remember from Section 5 — the SVM dual form only needs dot products of data points, never the points themselves. That's exactly what makes this substitution possible.
  • This substitution (replacing xi·xj with K(xi,xj)) is called kernel substitution.
  • Saves enormous computation — this is why it's called a "trick".

9Types of SVM Kernels

9.1 Linear Kernel

K(xi, xj) = xi · xj
  • Simplest kernel — it is basically no transformation at all (φ(x) = x).
  • Used when data is already linearly separable.
  • Fast to train, easy to interpret (weights directly show feature importance).
  • Best suited for: text classification, high-dimensional sparse data (e.g. spam detection, document classification) where number of features is already large.

9.2 Polynomial Kernel

K(xi, xj) = (γ·xi·xj + r)d
  • d = degree of the polynomial (controls flexibility of the curve — higher d = more complex boundary).
  • γ (gamma) = scaling factor for the dot product.
  • r = coefficient (constant term, controls influence of higher vs lower order terms).
  • Captures interaction between features (e.g. combinations like x1²x2), which linear kernel cannot.
  • Good when relation between classes is curved but has a clear polynomial-like pattern.
  • Risk: high degree d can easily overfit and becomes computationally heavy.

9.3 Gaussian / RBF Kernel (Radial Basis Function)

K(xi, xj) = exp( −γ ‖xi − xj‖² )    [also written with 1/2σ² instead of γ]
  • Most popular and most powerful/flexible kernel — default choice in most SVM libraries (e.g. sklearn's SVC).
  • Measures similarity based on distance — points close together get a value near 1, far apart get a value near 0.
  • Maps data into an infinite-dimensional feature space — can model extremely complex, non-linear boundaries.
  • γ (gamma) controls the "reach" of a single training point:
    • Large γ → small reach → boundary hugs the data tightly (risk of overfitting).
    • Small γ → large reach → boundary is smoother (risk of underfitting).
  • Great default when you have no prior knowledge of the data's shape.

Beginner mnemonic
Linear = straight ruler. Polynomial = a bendy French curve with a fixed "bendiness" (degree d). RBF/Gaussian = playdough that can mould into any shape around the data — most flexible of the three.

Other kernels that also exist (less commonly asked, good to know): Sigmoid kernel — K(xi,xj) = tanh(γxi·xj + r), behaves similar to a neural network's activation function.

Mercer's condition
Not every function can be used as a kernel. A valid kernel must satisfy Mercer's theorem — its kernel (Gram) matrix must be symmetric and positive semi-definite. This guarantees that a valid φ(x) mapping exists behind the kernel function.

10Properties of SVM

  • Maximum margin classifier — always tries to find the widest possible separating margin, giving good generalisation.
  • Effective in high-dimensional spaces — even works well when number of features > number of samples.
  • Memory efficient — decision function uses only support vectors, not the entire training set.
  • Versatile — different kernel functions can be specified for the decision function, so it adapts to many types of data.
  • Convex optimisation — the training problem is convex, so it always converges to a global optimum (no risk of getting stuck in local minima, unlike neural networks).
  • Robust to overfitting — especially in high-dimensional space, when margin/C is chosen well.
  • Works for both classification and regression (SVC and SVR).
  • Strong theoretical foundation — based on Statistical Learning Theory / VC dimension, so its generalisation behaviour is mathematically well understood.

11Issues / Limitations of SVM

  • Choice of kernel and parameters — performance depends heavily on selecting the right kernel and tuning C, γ, d; no universal rule, needs cross-validation.
  • Slow on large datasets — training time complexity is roughly O(n²) to O(n³) with number of samples n, so it becomes slow/impractical for very large datasets (e.g. millions of rows).
  • Poor performance with noisy / overlapping data — heavy class overlap or many outliers hurts accuracy even with soft margin.
  • No direct probability estimates — SVM outputs a class label, not a probability, by default (extra calibration like Platt scaling is needed to get probabilities).
  • Memory intensive kernel matrix — non-linear kernels require storing an n×n kernel matrix, which grows very large for big n.
  • Difficult to interpret — especially with non-linear kernels (RBF, polynomial), it's hard to explain "why" a decision was made, unlike decision trees.
  • Not naturally suited for multi-class problems — SVM is fundamentally a binary classifier; multi-class needs extra strategies like One-vs-One or One-vs-Rest.
  • Feature scaling required — SVM is sensitive to the scale of features; inputs must be normalised/standardised before training, or the kernel distances get distorted.
  • Sensitive to choice of C — wrong C can lead to overfitting (too strict) or underfitting (too loose).
Exam tip If asked "why not always use SVM for big data / deep learning problems?" → answer: training complexity O(n²–n³), memory-heavy kernel matrix, and no natural probability output — that's usually the expected answer.
